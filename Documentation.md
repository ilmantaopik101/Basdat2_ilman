# Sistem Informasi Akademik

## Deskripsi Project
Project sistem informasi akademik berbasis web menggunakan CodeIgniter 4.

---

## Fitur Sistem
- Login
- CRUD Mahasiswa
- CRUD Dosen
- CRUD Nilai

---

## Teknologi yang Digunakan
- PHP
- MySQL
- CodeIgniter 4
- Bootstrap

---

## Struktur Folder Project

```plaintext
app/
public/
tests/
vendor/
docs/
```

---

## Cara Menjalankan Project

### Install Dependency

```bash
composer install
```

### Copy Environment

```bash
cp env .env
```

### Jalankan Server

```bash
php spark serve
```
